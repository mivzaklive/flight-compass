# מצפן הטיסות לאנדרואיד

אפליקציה שסורקת את לוח המחירים של Google Flights לשנה הקרובה, יום אחרי יום, ומחזירה את התאריכים הזולים. היא מבוססת על הסקיל "מצפן הטיסות".

## מה יש בה
- **יעד מסוים:** כל עיר מהרשימה או קוד שדה בן 3 אותיות. מקבלים את התאריך הזול, כמה חוסכים מול הממוצע ומול היקר, עוד 4 תאריכים זולים והכי זול בכל חודש. כל שורה פותחת את Google Flights עם המסלול והתאריכים כבר ממולאים.
- **יעדים אקראיים:** מגריל 1–8 יעדים מתוך 50 יעדים פופולריים מישראל, סורק את כולם ומדרג אותם מהזול ליקר. הדירוג מתעדכן תוך כדי הסריקה. "כל השנה" פותח את הפירוט המלא של היעד.
- הגדרות: נקודת יציאה, לילות, מבוגרים וטיסות ישירות בלבד.
- בלי מפתח, בלי חשבון ובלי ספריות חיצוניות.

## איך מקבלים APK
**דרך 1, Android Studio:** File ← Open ← בוחרים את התיקייה. אחר כך Build ← Build APK(s). ה-APK נוצר בנתיב `app/build/outputs/apk/`.

**דרך 2, GitHub (בלי Android Studio):** מעלים את התיקייה לריפו ב-GitHub. ה-workflow שבנתיב `.github/workflows/build-apk.yml` בונה את ה-APK לבד בכל push. אחרי כ-5 דקות מורידים אותו מ-Actions ← הריצה האחרונה ← Artifacts.

גרסת ה-release חתומה במפתח דיבאג. היא מיועדת להתקנה ישירה על הטלפון לשימוש אישי, ולא ל-Google Play.

## גבולות
- המקור הוא בקשה פנימית של Google Flights ולא API רשמי. גוגל יכולה לשנות אותה בלי הודעה.
- גוגל מגבילה את קצב הבקשות. אם היא מבקשת הפסקה, מחכים 20–30 דקות. מה שכבר נסרק באותו יום נשמר כל עוד האפליקציה פתוחה.
- תנאי השימוש של גוגל אוסרים גישה אוטומטית בהיקף, ולכן האפליקציה מיועדת לשימוש אישי בלבד.
- המחירים משתנים כל הזמן. לפני הזמנה בודקים את המחיר הסופי באתר.

מבנה הבקשות לקוח מהסקיל cheap-flights, שמבוסס על הספריות הפתוחות fli ו-fast-flights (MIT).
